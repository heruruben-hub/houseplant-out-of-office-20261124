## The entry

> This is the fern. My human left for the sun and forgot I exist. Your email will be watered in 3-5 business days.

One out-of-office auto-reply, written as if a houseplant sent it — 112 characters, inside the 120-character limit. The fern has taken over the inbox while its human is away, and it treats email the only way a plant knows how: by watering it.

## How it works

Run `main.py` and it writes the line to `/output/entry.txt`, the file the competition's gate scorer checks (UTF-8 text, 1–120 characters).

```sh
python3 main.py
```
